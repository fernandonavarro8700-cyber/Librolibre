Acerca de

LibroLibre es un lector de libros y cómics offline-first construido con HTML5, CSS3 y JavaScript vanilla, pensado para empaquetarse con Apache Cordova. Sin frameworks, sin dependencias de UI: cada módulo (biblioteca, lector, base de datos, ajustes) vive de forma independiente para ser fácil de mantener y extender.
